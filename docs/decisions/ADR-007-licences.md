# ADR-007: Licences

Status: accepted; the per-package list is **pending the first build's licence manifest**. Date: 2026-11-15.

## Context

The image mixes this project's code, copyleft software (GNSS-SDR, GNU Radio, the kernel), permissively licensed libraries and proprietary firmware. The licences were read from the upstream files at the pinned revisions ([research](../research.md)); the summary for users is in [LICENSES.md](../../LICENSES.md).

## Decisions

1. **This repository stays GPL-2.0-only**, as before, with the per-file exceptions already present (MPL-2.0 for the LED matrix code, BSD-3-Clause for the protobuf definitions). New recipes and scripts follow the repository's licence. The receiver profiles derive from GNSS-SDR's examples and are GPL-3.0-or-later.
2. **Recipes declare the real licence of what they build**, with `LIC_FILES_CHKSUM` pointing at the licence file in the fetched source (checksums computed from the pinned sources on 2026-11-15). `tests/test-recipe-metadata.sh` fails on a recipe without them.
3. **Code taken from other layers is attributed** in the recipe header (`armadillo`, `matio` from `meta-gnss-sdr`, MIT).
4. **GPL-2.0-only and GPL-3.0 programs coexist as separate processes.** The web monitor talks to GNSS-SDR over UDP and to the microcontroller's router over a socket; nothing GPL-2.0-only links against GPL-3.0 code.
5. **Every build produces its own compliance material**: SPDX SBOM (`create-spdx`), the licence manifest in the deploy directory, and the licence texts inside the image (`COPY_LIC_MANIFEST`, `COPY_LIC_DIRS`).
6. **No GPL-3.0 exclusion.** GNSS-SDR and GNU Radio are GPL-3.0; the image does not set `INCOMPATIBLE_LICENSE`. In return the device must stay open to modified software, which it is: this project adds no boot lock.
7. **Firmware is not redistributed by this repository.** The recipes that fetch Qualcomm's boot firmware and the linux-firmware blobs belong to the BSP layers; this repository contains none of those files. A built image does contain them, so publishing an image requires reading their terms first.
8. **Test data is not redistributed.** The capture's publisher states no licence; the repository only documents it and downloads it on request.

## Open points

- The licence list of the web monitor's npm dependencies in the recipe's `LICENSE` field was written from knowledge of those packages. Compare it with the build's licence manifest after the first build and correct the recipe if they differ.
- `arduino-router`'s Go module licences are generated by `bitbake -c update_modules` into `arduino-router-licenses.inc`; that file does not exist yet.
- `meta-sdr` has no licence file at its top level. It is used as a layer (not copied); note it if recipes are ever copied from it.
